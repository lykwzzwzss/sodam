# UI 规范（sodam）

视觉目标：复刻汽水音乐桌面端的层级、比例与手感（纯本地内容，不含任何在线模块）。
本文记录现行约束，页面不要各自引入新的尺寸/颜色规则。

## 1. 参考

- 汽水音乐 Windows 客户端（Vue 3 + SCSS）：布局比例、播放栏、侧栏、弹层。
- 本地曲库页与「正在播放」页的排版由本仓库实现，数据来自内嵌封面/歌词。

## 2. 主题与颜色

- 固定深色主题，不提供明暗切换。
- **结构色**是固定的白色透明度阶梯：
  - 主文本 `.94`、次文本 `.63`、弱文本 `.38`；
  - 悬停面 `.09`、选中面 `.13`、卡片 `.035`、描边 `.08`。
- **主题色**来自当前封面：
  - `sodam-core::artwork` 在 OKLab 里聚类，输出 `accent`（活力色）、`dominant`、
    `ambient` 与 9 阶 `base-1..9`；
  - 背景用 `base-5 → base-7` 渐变；侧栏/播放栏用半透明 `base-7`；
  - 进度/高亮用 `base-3`；灰白封面退回中性灰阶 + 品牌绿 `#00CB64`。
- 全窗背景 = 9 阶色板纵向渐变 + 活力色/环境色柔光 + 暗化 scrim；
  **不**使用封面模糊图。切换歌曲时整页色板一起过渡（520ms）。
  不要在整页上叠加 `backdrop_blur`（背后只有平滑色场，没有视觉收益）。
- 队列侧板与菜单用 `glass_panel()` + `.backdrop_blur(24~32px)`。

## 3. 尺寸

当前基准（逻辑像素）：

- 启动窗口：客户区 **2100 × 1400 物理像素**，主屏居中；按显示器缩放换算逻辑尺寸。
- 最小窗口：1120 × 720。
- 侧栏：**256**；顶栏：**60**；播放栏：**112**；队列侧板：**420**。
- 内容区左右内边距 32。
- 本地页歌单头图：**200**；播放页大封面：**360**。
- 播放栏：封面 **68**、播放胶囊 **100 × 56**、上一首/下一首 **64 × 56**、
  图标按钮 40、音量条 96。
- 列表行：**56**；侧栏行：44；播放页歌词行：56。
- 间距：4 / 8 / 12 / 16 / 24 / 32。
- 圆角：封面 8 / 小封面 4 / 卡片 12 / 胶囊 999。
- 图标：16 / 20 / 26 / 32；播放图标 26。
- 字号：11 / 13 / 15 / 18 / 26 / 32；字重只用 500 / 600。

## 4. 布局

### 侧栏

- 品牌行（30 logo + 22/600 `SodaM`）→ 「本地音乐」行 → 「歌单 · N」分组 →
  可滚动歌单行（图标 + 名字 + 曲数）→ 底部「设置」。
- 品牌行是窗口拖拽区（Windows 自绘标题栏）；行悬停 `.05`、选中 `.1`。

### 顶栏

- 高 60，半透明黑条；中部是一个 34 高胶囊：文件夹图标 + 路径 + 曲数 + 下拉箭头，
  点击打开文件夹选择框。
- 右侧：重新扫描（图标）、更改文件夹（白底黑字胶囊）、窗口控制（44×60 ×3）。
- 播放页展开时顶栏换成：返回按钮 + 「正在播放」+ 拖拽区 + 窗口控制。

### 本地音乐页

- 歌单头图 200 + 「歌单」标签 + 32/600 标题 + 曲数 + 白色「播放全部」+ 随机按钮。
- 下方「歌曲 · N 首」+ 表头（# / 标题 / 歌手 / 时长）+ 56 行高虚拟列表。
- 正在播放行：序号位置 `♪` 用主题色；不要整行染色。
- 空态必须出现：未选文件夹给引导；扫描失败给可行动原因；空歌单不空页。

### 播放页（点播放栏封面/标题/词按钮）

- 内容居中：360 大封面 + 下方左对齐标题/歌手/专辑；右侧 560 宽歌词。
- 歌词 26/600（超过 34 字符自动降到 21）；当前行白 `.94`，其他 `.5`；
  当前行随播放位置居中滚动，点击行 seek 到对应时间。
- 无歌词显示「这首歌没有内嵌歌词」+ 支持格式说明。

### 播放栏

- 顶部 2px 全宽进度线（hover 出 10px 圆点，拖动预览、松手 seek）。
- 左：68 封面（hover 出现展开图标，点击进播放页）+ 标题/歌手 + 引擎错误行。
- 中：时间文本 + 上一首 + 100×56 播放胶囊 + 下一首。
- 右：词、播放模式、音量、96 宽音量条、队列开关。
- 装载中：播放胶囊换 spinner、进度线降透明度并禁用拖动。

### 队列侧板

- 覆盖在内容右侧的 420 宽磨砂侧板（不挤压页面），底部让出播放栏；
  关闭按钮在**左侧**（右侧会与窗口控制按钮重叠，实测会误触最大化）。
- 三段：已播放 → 正在播放 → 接下来；行高 64，44 封面，当前行主题色。
- 右键菜单只有「从队列移除」；正在播放的曲目不弹菜单。

### 状态反馈

- 普通状态只写 `Root::status_line`，不默认弹全局 message。
- 状态行固定在播放栏上方、内容区左侧，绝对定位；5 秒消失，新状态顶掉旧状态。
- 全局 message 只用于需要用户注意的事件；同一来源稳定 key 替换，最多 4 条。

## 5. 文案与 i18n

- 用户可见文案必须走 `root.tr` / `root.localized`。
- 中文原文作为稳定 key，英文词典在 `ui/i18n.rs`（静态守卫测试兜底）。
- 命名占位符（`{err}`、`{added}`）按顺序填充。

## 6. 动效

- 页面切换：180ms 淡入（`ease_out_quint`），id 随页面变化重播。
- 背景切歌：520ms 交叉淡化（旧图淡出 / 新图淡入）。
- 播放页封面换歌：360ms 淡入。
- 队列侧板：260ms 从右侧滑入。
- 悬停/按压：颜色瞬时切换（汽水音乐本身也没有 hover transition）；
  仅播放按钮/封面用 `active` 轻微缩放。
- 不使用整窗大 blur 动画；所有动画都应尊重 `App::reduce_motion`。

## 7. 性能约束

1. 渲染路径禁止网络请求和阻塞 IO。
2. 长列表使用 `uniform_list`，只渲染可见项；滚动条宽度设为 0。
3. 渲染只读取 `Arc` 缓存（曲库、队列快照、歌词），不深拷贝大列表。
4. 封面/歌词/色板全部在后台线程准备，结果回 UI 后整体替换。
5. `SODAM_FRAME_LOG=1` 观察超过 16ms 的帧；`SODAM_SCROLL_TEST=1` 做滚动压测。
6. 队列/菜单的 `backdrop_blur` 会让整帧走离屏合成，避免在常驻大区域使用。

## 8. GPUI 版本与本地补丁

使用 `sodahub-org/gpui` fork（rev `5ff26c7`）。本仓库为「按物理像素固定客户区」
补了 `PlatformDisplay::physical_size()`（Windows 后端返回显示器物理尺寸）。
升级 gpui rev 时必须重放这两个文件的补丁：
`crates/gpui/src/platform.rs`、`crates/gpui_windows/src/display.rs`。
