# Roadmap

当前仓库已经从「汽水音乐在线客户端」收敛为**纯本地音乐播放器**（文件夹即歌单，
免登录、不联网）。本文记录已完成能力与下一阶段工作。

## 已完成

- [x] GPUI 主窗口、侧边栏、内容路由、底部播放栏
- [x] 固定深色主题
- [x] 配置文件读写；播放模式；语言设置
- [x] 本地文件夹音乐库：文件夹即歌单，后台扫描，离线播放
- [x] rodio 播放线程、进度、音量、播放模式、自然播完切歌
- [x] 队列视图（已播放 / 正在播放 / 接下来）、右键移除
- [x] 列表虚拟化、滚轮平滑滚动
- [x] 内嵌封面：OKLab 取色、9 阶主题色、整页色场、切歌颜色过渡
- [x] 「正在播放」页：大封面 + 内嵌歌词（LRC / USLT，支持同名 `.lrc`）同步高亮
- [x] 点击播放栏封面/标题展开播放页；歌词行点击跳转
- [x] 中英文界面、系统托盘、关闭到托盘
- [x] 系统媒体控制：Windows SMTC / macOS Now Playing / Linux MPRIS
- [x] Arch Linux ARM64 打包与桌面入口
- [x] 移除全部联网/登录能力（libresoda、缓存下载、预取、播放上报、签名）

## 近期优先级

### 1. 本地库增强

- [ ] 歌单内搜索过滤
- [ ] 手动拖拽排序 / 曲目编辑（改文件名、标签）
- [ ] 多文件夹支持（一个根目录 → 多个根目录）
- [ ] Linux 下文件夹选择对话框（`rfd` 的 XDG portal 通路，当前仅 Windows 可用）
- [ ] 歌词逐字/逐行动画（当前为整行高亮 + 居中滚动）

### 2. 音质与格式

- [ ] Opus 解码支持（Symphonia 0.5 尚无，等上游或换解码器）
- [ ] 无标签回退展示的分类整理（未知歌手聚集）

### 3. 稳定性

- [x] 重启后恢复上次的播放队列、进度与浏览的歌单
- [ ] 更多离线测试覆盖 queue、扫描边界、设置迁移

### 4. 发布

- [ ] 配置文件版本迁移（旧在线版 config.json 字段顺滑丢弃）
- [ ] 干净机器安装测试（Windows 安装脚本 / Arch PKGBUILD）
- [ ] 自动化 CI（fmt + clippy + test）

## 非目标

- 不做任何网络请求：没有公共签名代理、没有会员权益判断、没有账号体系。
- 不分发官方客户端二进制或用户凭据。
