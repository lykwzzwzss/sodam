# UI 交互与状态变化清单

统计当前版本所有「用户操作 → 界面变化」的可感知路径。每条都写明：
**触发方式 / 变化对象 / 从什么变成什么 / 过渡动画**。

动画参数来自 `crates/sodam/src/ui/motion.rs`（规范见 [MOTION.md](MOTION.md)）；
「瞬时」表示没有过渡，下一帧直接切换。

---

## 1. 窗户与标题栏

| 触发 | 变化对象 | 从 → 到 | 过渡 |
| --- | --- | --- | --- |
| 悬停最小化/最大化/关闭 | 按钮底色 | 透明 → 6% 白 | **120ms 淡入** |
| 悬停关闭 | 按钮底色 | 透明 → 品牌红 `#c42b1c` | **120ms 淡入** |
| 悬停控制图标 | 图标颜色 | 94% 白 → 纯白 | **120ms 插值** |
| 离开控制按钮 | 底色/图标 | 恢复原状 | **120ms 淡出/插值** |
| 点击最大化/还原 | 窗口状态 + 中间图标 | 单方框 ⇄ 两个叠起来的方框 | 瞬时（系统改窗口状态后重绘） |
| 点击最小化 | 窗口 | 显示 → 最小化 | 系统动画 |
| 点击关闭 | 窗口 | 显示 → 隐藏到托盘 | 系统动画 |

| 拖动边缘 | 窗口尺寸 | 跟随指针 | 系统缩放 |

## 2. 顶栏（非播放页）

| 输入/删除字符 | 结果列表 + 计数 | 按关键字实时过滤 | 每键立即重排（不播列表动画） |

| Esc | 搜索状态 | 先撤输入法组合 → 取消选区 → 清空查询 → 失焦 | 瞬时 |
| Ctrl/Cmd+F | 焦点 | 任意控件 → 搜索框 | **140ms 描边过渡** |

播放页顶栏只有返回、标题和窗口控制：刷新与文件夹按钮不显示。

## 10. 目前仍是「瞬时切换」的位置

按用户可感知程度排序：

1. **轻提示堆叠位移**：删除一条时其余提示瞬时上移（需要 FLIP）。
2. **窗口最大化图标**：随系统窗口状态瞬时切换（与原生标题栏一致）。
3. **播放页与本地页之间的共享封面**：目前是整页淡入，不是小封面展开成大封面。
4. **队列抽屉打断**：关闭途中再次打开会从屏外重新滑入，不是从当前位置反向。
5. **进度/音量拖拽**：按设计保持完全跟手，不加缓动。
6. **搜索逐字符过滤**：按设计即时更新，只对模式切换做过渡。
7. **错误条消失**：错误解决后瞬时移除（出现有 180ms 淡入）。

前四项是后续可以继续投入的方向；后三项是刻意保留的「跟手/即时」行为。
